## Persona A — 고령층 사용자

### 기본 정보
```
이름: 김순자
나이: 78세, 여성
거주: 서울 강서구 (독거)
학력: 초졸
직업: 은퇴 (이전 청소부)
스마트폰: 갤럭시 A 시리즈 (화면 크기 확대 설정)
사용 앱: 카카오톡 only
```

### 디지털 리터러시 분석
```
문자 메시지:        ★★☆☆☆ (자녀가 보낸 것만 읽음)
카카오톡:            ★★★☆☆ (응답은 가끔)
버튼/터치:          ★★☆☆☆ (손 떨림으로 오터치 빈번)
스크롤:             ★☆☆☆☆ (위 아래 구분 어려움)
설정:              ★☆☆☆☆ (절대 건드리지 않음)
새 앱 설치:        ★☆☆☆☆ (거부감 매우 높음)
```

### 신체적 제약
```
시력: 노안 심함 (약 100배 확대 필요)
청력: 중간~고주파 감소 (알림음 큰 톤 선호)
손가락: 관절염으로 미세 운동 어려움 (큰 버튼만 가능)
반응속도: 1~2초 지연 (3초 이내 인지 불가)
피로도: 오후 3시 이후 집중력 급감
```

### 일과 패턴
```
06:00 기상
09:00 아침 식사 (주로 혼자)
09:30 TV 시청
12:00 점심 (복지관 or 혼자)
14:00 낮잠
16:00 산책 또는 집안일
18:00 저녁 식사
19:00 TV
21:00 취침
```

### 카카오톡 사용 패턴
```
카톡 체크: 아침(8~10시), 오후(2~4시), 저녁(7~8시) 3회
응답 시간: 평균 5분 (알림 확인 후)
실패 원인:
  - 안경 안 쓰고 못 봄
  - 버튼을 못 찾음
  - 오터치로 엉뚱한 것 누름
  - 카톡 알림을 놓침
```

### 심리 상태
```
기본 정서: 외로움 (매일 1시간 이상 혼자)
불안감: 아들(서울 거주)이 자신을 잊을까
신뢰도: 낯선 것에 매우 민감
자존감: 스스로 "디지털 약자"라고 생각
동기: "아들이 걱정할까봐" 응답 시도
```

### 응답하는 이유
> "우리 아들이 일이 바쁜데, 내가 응답을 안 하면 미안하지."

**핵심**: 의무감 + 죄책감 (긍정이 아님)
→ 압박감을 주면 응답 거부 가능

## Persona B — 복지사 / 지자체 담당자

### 기본 정보
```
이름: 이민지
나이: 34세, 여성
직급: 사회복지사 (경력 8년)
소속: 강서구청 장애인복지과
근무: 월~금 09:00~18:00
학력: 사회복지학 학사
```

### 업무 현황
```
담당 인원: 87명 (독거노인 + 장애인)
방문 주기: 월 2회 이상
전화 상담: 주 20건 이상
서류 작업: 하루 1시간 이상

업무 구성:
- 현장 방문: 40%
- 전화 상담: 30%
- 서류/기록: 20%
- 회의/보고: 10%
```

### 현재 도구 & 프로세스
```
기록 도구: 엑셀 + 수기 일지
연락 방식: 모바일 전화
상태 확인: 엑셀 목록 + 기억
우선순위 판단: 개인 경험 기반 (문서화 없음)

전형적인 하루:
09:00 출근 → 어제 기록 정리 (30분)
09:30 위험자 판단 (20분) ← 매우 비효율
09:50 현장 방문 (3명, 2시간)
12:00 점심
13:00 전화 상담 (6명, 2시간) ← 통화 중 기록 병행 불가
15:00 기록 작성 (1시간) ← 메모 기반 후기 작성 = 오류 높음
16:00 문서/보고서 (1시간)
17:00 퇴근
```

### 최대 고통점 (Pain Points)
```
1. "위험도 판단에 30분"
   → 엑셀 여러 시트 확인
   → 누구를 먼저 전화할지 기억에 의존
   → 매일 반복

2. "통화 후 기록을 못 함"
   → 방문 중 메모 불가능
   → 저녁에 기억으로 작성
   → 오류 빈번

3. "위험자를 놓칠까봐 불안"
   → 혼자 판단할 수 없음
   → 체계화된 기준 없음
   → 책임 리스크 높음

4. "보고서 작성 시간"
   → 월간 보고서 6시간 소비
   → 수기 집계
   → 착오 가능성

5. "초과 근무"
   → 평균 주 3시간 추가 근무
   → 대가 없음
   → 소진(Burnout) 진행 중
```

### 필요한 것 (Needs)
```
1순위: "지금 이 사람 전화해" 1초 판단
  → 우선순위 자동화
  → AI 기반 제안

2순위: 통화 후 30초 기록
  → 팝업 형식
  → 음성 입력 지원
  → 자동 저장

3순위: 위험도 객관화
  → 우리 판단이 맞다는 확신
  → 책임 근거 확보

4순위: 자동 보고서
  → 월간 보고서 자동 생성
  → 수정만 가능

5순위: 팀 간 정보 공유
  → 담당자 부재 시 보조자가 即 처리
  → 핸드오프 명확화
```

### 성공 정의
```
"하루 일과 중 
 위험 판단에 3분, 
 기록에 0분을 쓸 수 있다면, 
 나는 방문에 2시간을 더 쓸 수 있다."
```

### 동료 피드백 (현장 음성)
> "지금 우리는 기록을 하기 위해 현장을 가는 게 아니라, 현장을 다녀와서 기록을 하기 위해 야근하는 중이에요."

## Persona C — 보호자 (성인 자녀)

### 기본 정보
```
이름: 박성민
나이: 52세, 남성
직급: 회사원 (마케팅 팀장)
소재: 서울 (부모 광주 거주)
결혼: 기혼, 자녀 2명
```

### 부모 상황
```
아버지: 81세, 고혈압 관리 중
어머니: 78세, 당뇨 관리 중
거주 형태: 광주 독거 (부부)
연락 빈도: 주 3회 전화 + 가끔 방문
```

### 불안감 패턴
```
"엄마가 왜 전화를 안 받지?"
  → 10분 후 불안감 증가
  → 30분 후 약간의 패닉
  → 1시간 후 심각한 불안
  → 자의적으로 또 전화 (4~5회 반복)

결과: 어머니 짜증 + 관계 악화
```

### 현재 정보 수집 방식
```
수단:
1. 부모에게 매일 전화
2. 지난주 담당 복지사 전화 (1회)
3. 어머니 SNS 확인 (가끔)

문제:
- 신뢰도 낮음 (부모는 "괜찮다"고만 함)
- 빈도 낮음 (복지사는 바쁨)
- 객관성 없음 (부모 증상 변화 모름)
```

### 필요한 것 (Needs)
```
1순위: "엄마 안전한지만 빠르게 확인"
  → 1초 판단
  → "정상" vs "확인 필요"

2순위: "응답 없을 때만 알림"
  → 매일 알림은 과도
  → 이상 징후 시에만

3순위: "담당 복지사와 빠른 연결"
  → 비상 시 즉시 연락
  → 평상시는 방해 안 함

4순위: "과거 상태 추세 파악"
  → 최근 1개월 응답 패턴
  → "예전 같지 않다"는 느낌 검증
```

### 심리 상태
```
기본 정서: 미안함 (멀리 떨어져 있어서)
불안감: 갑자기 쓰러질까 두려움
자책감: 이런 시스템이 없으면 나쁜 아들로 느낌
신뢰도: 기관이나 AI 보다는 "인간관계"를 원함
```

### 동료 피드백 (공통 음성)
> "매일 엄마한테 전화하는데, 뭔가 잘못된 느낌이 들어도 확인할 방법이 없어요."

## Persona 별 우선순위 정렬

### Persona A (고령층) 기준
```
1순위: 응답 가능성 (버튼 찾을 수 있나)
2순위: 감정적 안정감 (혼자가 아니라는 느낌)
3순위: 실수 수정 가능성 (잘못 눌렀을 때)
```

### Persona B (복지사) 기준
```
1순위: 위험도 자동 판정 (판단 시간 → 3분)
2순위: 자동 기록 (기록 시간 → 0분)
3순위: 의사결정 근거 제공 (책임 확보)
```

### Persona C (보호자) 기준
```
1순위: 상태 즉시 확인 (1화면, 3초)
2순위: 무응답 시에만 알림 (과도 알림 금지)
3순위: 복지사 신뢰도 증명 (누군가 보고 있다)
```

### Persona D (지자체) 기준
```
1순위: 정량적 지표 (고독사 감소 수치)
2순위: 예산 효율 (1인당 비용 계산)
3순위: 확장 가능성 (다른 구/광역시)
```
