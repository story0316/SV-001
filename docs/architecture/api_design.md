## 1. KakaoTalk Bot API

### Webhook: POST /api/kakao/messages

**받는 데이터**:
```json
{
  "userId": "kakao_1234567",
  "userKey": "unique_identifier",
  "content": "button_key",
  "createdTime": "2026-05-29T09:15:00Z"
}
```

**처리**:
- daily_responses 레코드 업데이트
- 위험도 재계산
- 감사 메시지 발송
- 보호자/복지사 Realtime 업데이트

**응답**:
```json
{
  "status": "success",
  "processed": true
}
```

## 2. Guardian API (보호자 앱)

### GET /api/guardian/status/:parentId

**설명**: 부모 오늘 상태 조회

**응답**:
```json
{
  "name": "김순자",
  "age": 78,
  "status": "normal|warning|danger",
  "lastResponseTime": "2026-05-29T09:15:00Z",
  "lastResponseAgo": "2h",
  "riskScore": 42,
  "assignedWorker": {
    "name": "이민지",
    "phone": "010-XXXX-XXXX"
  }
}
```

### GET /api/guardian/history/:parentId?days=7

**설명**: 최근 N일 응답 패턴

**응답**:
```json
{
  "history": [
    { "date": "2026-05-29", "responded": true, "time": "09:15" },
    { "date": "2026-05-28", "responded": true, "time": "09:22" },
    { "date": "2026-05-27", "responded": false },
    ...
  ]
}
```

## 3. Welfare Dashboard API (복지사)

### GET /api/welfare/dashboard/today

**설명**: 오늘 대시보드 (우선순위 정렬)

**응답**:
```json
{
  "critical": [
    {
      "clientId": "uuid",
      "name": "김순자",
      "age": 78,
      "district": "강서구",
      "riskLevel": "critical",
      "riskScore": 87,
      "riskReasons": ["3일 무응답", "패턴 이상"],
      "lastResponse": "2026-05-26T09:15:00Z",
      "contactAttempts": 2
    }
  ],
  "today": [],
  "pendingTasks": []
}
```

### POST /api/welfare/contact/:clientId

**설명**: 통화/방문 기록 저장

**요청**:
```json
{
  "result": "completed|missed|rejected|unreachable",
  "status": "normal|warning|danger",
  "actions": ["check_health", "hospital_referral"],
  "note": "Optional memo text or voice URL",
  "nextContact": "2026-05-30T09:00:00Z"
}
```

**응답**: 저장된 기록 ID + Realtime 브로드캐스트

### GET /api/welfare/client/:clientId

**설명**: 대상자 상세 정보

**응답**:
```json
{
  "profile": { /* 기본 정보 */ },
  "riskScore": 87,
  "riskFactors": [ /* 위험 요인 */ ],
  "responseHistory": [ /* 응답 히스토리 */ ],
  "contactLog": [ /* 연락 기록 */ ],
  "notes": [ /* 메모 */ ],
  "guardian": { /* 보호자 정보 */ }
}
```

### POST /api/welfare/guardian-notify

**설명**: 보호자 알림 발송

**요청**:
```json
{
  "clientId": "uuid",
  "guardianId": "uuid",
  "type": "unresponsive|warning|update",
  "message": "알림 메시지",
  "autoGenerated": true
}
```

## 4. Admin API (B2G, 향후)

### GET /api/admin/stats/daily

**설명**: 일일 통계

```json
{
  "date": "2026-05-29",
  "totalClients": 87,
  "responded": 71,
  "responseRate": "81.6%",
  "riskDetected": 4,
  "actionsCompleted": 3
}
```

### GET /api/admin/report/monthly

**설명**: 월간 보고서 생성

**응답**: PDF 파일 또는 HTML

## 5. Internal Services

### Risk Detection Engine

**트리거**:
- 매일 06:00 전체 재계산
- 응답 수신 후 즉시
- 이상징후 감지 시

**입력**:
```
clientId, responseHistory[], contactLog[], etc.
```

**출력**:
```
riskScore (0-100),
riskLevel (critical|high|medium|safe),
riskFactors: string[],
notification: boolean
```
